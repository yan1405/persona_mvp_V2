Circular icon-only button for header utilities, message actions and the composer.

```jsx
<IconButton icon="bell" dot label="Notificações" />
<IconButton icon="arrow-up" variant="solid" size={36} label="Enviar ao Agente Persona" />
```

- `variant`: ghost (default) | outline | soft (indigo tint) | solid (ink) | brand
- Always pass `label` for accessibility.
